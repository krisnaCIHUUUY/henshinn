# Badge

Satu atau dua kata status di samping nama; warnanya selalu berarti sesuatu.

| Badge | Tone | Di mana |
|---|---|---|
| Selesai | `success` | Riwayat, detail transaksi |
| Void | `danger` | Riwayat, detail transaksi (transaksi tetap terlihat, harga dicoret) |
| Sisa 3 | `warning` | Produk dengan stok ≤ batas menipis |
| Habis | `danger` | Produk stok 0; di kasir barisnya redup dan tidak bisa ditambahkan |
| Nonaktif | netral | Produk yang disembunyikan dari kasir |

Hanya dua tone status yang dipakai di Riwayat, karena transaksi hanya punya dua status. Tidak ada "Diproses" atau "Diskon". Badge tidak bisa ditekan.
